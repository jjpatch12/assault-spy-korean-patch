# Assault Spy 한국어 패치
<img width="616" height="353" alt="image" src="https://github.com/user-attachments/assets/38ef87cd-0682-4394-b614-f941764bb4f4" />

Assault Spy 일본어 슬롯을 교체하는 비공개 한국어 패치입니다. 현재 배포 버전은 **v1.0**입니다.

## 다운로드 및 설치

저장소의 **Releases → v1.0**에서 `AssaultSpy_KoreanPatch_v1.0.zip`을 내려받습니다.

1. ZIP 전체를 압축 해제합니다.
2. 게임을 완전히 종료합니다.
3. `AssaultSpy_KoreanPatch_Installer.bat`을 실행합니다.
4. 게임 폴더를 자동으로 찾지 못하면 `Assault Spy` 최상위 폴더를 입력합니다.


자세한 범위와 한계는 [PATCH_SCOPE_KO.md](PATCH_SCOPE_KO.md)를 확인하세요.


## v1.0 ZIP 무결성

릴리스에 첨부된 `AssaultSpy_KoreanPatch_v1.0.zip.sha256` 또는 저장소의 `checksums` 폴더에서 SHA-256을 확인할 수 있습니다.
